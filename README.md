# camillia-app-win

WinUI 3 (Windows App SDK) app for Camillia. Logic lives in [camillia-app-core](https://github.com/oumike/camillia-app-core),
included as a git submodule at `core/` and called through C# bindings generated by
[uniffi-bindgen-cs](https://github.com/NordSecurity/uniffi-bindgen-cs).

Must be built and run on Windows 10 1809+ / Windows 11 (x64 or ARM64). On an Apple Silicon Mac,
a Windows 11 ARM VM (Parallels, VMware Fusion or UTM) works.

## One-time setup (Windows)

1. **Visual Studio 2022+** with the *WinUI application development* workload
   (or just the .NET 10 SDK if you prefer the CLI). This also provides the MSVC build tools Rust needs.
2. **Rust**: install from <https://rustup.rs> (default MSVC toolchain).
3. **C# binding generator** (version must match core's pinned uniffi):
   ```powershell
   cargo install uniffi-bindgen-cs --git https://github.com/NordSecurity/uniffi-bindgen-cs --tag v0.11.0+v0.31.0
   ```

## Build and run

```powershell
git clone --recurse-submodules https://github.com/oumike/camillia-app-win.git
cd camillia-app-win
scripts\build-core.ps1                 # builds core -> Generated\ (rerun after core changes)
dotnet run --project src\CamilliaWin
```

Or open `CamilliaWin.sln` in Visual Studio, select the platform matching your machine (x64 or ARM64) and press F5.
The core DLL is built for the host architecture, so the app platform must match it.

## Updating core

```powershell
git submodule update --remote core
scripts\build-core.ps1
git commit -am "Bump core"
```
